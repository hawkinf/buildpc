# Recursos visuais do BuildPC

- `Icons.axaml`: geometrias vetoriais usadas por navegação, componentes,
  ações, filtros e estados de compatibilidade.
- `Colors.axaml`: paleta e pincéis dos temas da interface.
- `../Styles/Controls.axaml`: estilos compartilhados dos controles.
- `../Assets/Brand/buildpc.svg`: fonte vetorial da marca.
- `../Assets/Brand/buildpc.png`: imagem de marca empacotada no aplicativo.
- `../Assets/Brand/buildpc.ico`: ícone nativo da janela e do executável.

Os dicionários são carregados em `App.axaml`. A pasta `Assets` é incluída como
`AvaloniaResource` no projeto desktop.
